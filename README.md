# 📊 Power BI Sales Performance & Forecasting Dashboard

## 📌 Project Overview
An end-to-end Power BI project built to analyze sales data, track revenue metrics, evaluate regional performance, and forecast future sales trends using Power Query, DAX, and advanced predictive analytics.

## 🎯 Business Objectives
* Analyze total revenue, profit margins, sales volume, and customer trends across regions.
* Clean and transform raw sales data using Power Query Editor.
* Develop custom DAX measures for key metrics and dynamically calculated tables.
* Design an intuitive, interactive 2-page report for executive decision-making.
* Build a time-series forecasting model to predict future sales patterns.
